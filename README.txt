Nácar website (version 2)

Run it:  double-click start-nacar.bat. Your browser opens http://localhost:8080
Stop it: close the black server window.

Pages: index.html (landing), faro.html (phone), pulso.html (watch), onda.html (earbuds).
brand/   Nácar logo files (SVG): horizontal, stacked, symbol, mono symbol, wordmark, favicon.
assets/  Product renders (original, generated for Nácar), desktop + "-m" mobile sizes.
v1-previous/  The first version of the site, kept for reference.

Nácar is a fictional brand created as a design study.
